# My First Codex Project
This is my first project using OpenAI Codex.

## StepUp Learning

A colorful, mobile-friendly educational website with English, Urdu, Maths and Islamiat sections. Each subject includes a starter lesson and an interactive quiz.

### How to open the website

1. Download or clone this repository onto your computer.
2. Open the repository folder.
3. Double-click `index.html` to open it in Chrome, Edge, Firefox or Safari.
4. Keep `style.css` and `script.js` in the same folder as `index.html`.
5. Click **Start your adventure** and choose a subject to try a lesson.

No installation or internet connection is required. You can also open `preview.html`, which contains the complete website in a single file.

To try the mobile layout, make your browser window narrow. Use the **Menu** button to navigate. Close a lesson with its **X** button or the **Escape** key.

### Website files

- `index.html` — homepage, four subject sections and lesson dialog.
- `style.css` — colors, layout, responsive styles and keyboard focus indicators.
- `script.js` — mobile menu, lessons and quiz feedback.
- `preview.html` — standalone preview of the same website.

When editing the website, update the three source files above. The standalone preview is a snapshot and must be regenerated after changes.
